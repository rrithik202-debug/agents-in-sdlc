現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を活用します。変更を計画し、コードを作成し、動作をテストし、プルリクエストをレビューし、エージェントと作業を管理する反復的な流れを体験します。

## シナリオ

架空の企業 Tailspin Toys で新しく開発者として働きます。同社は開発者をテーマにしたボードゲームのクラウドファンディングを運営しています。チームのバックログは GitHub Issue として用意されています。カテゴリやページネーションによる絞り込みなどの機能開発に加えて、アクセシビリティやコーディング規約の改善にも取り組みます。

## 作業環境を選ぶ

GitHub Copilot は、普段の作業環境で利用できます。作業方法に合った環境を選んでください。各ワークショップはそれぞれセットアップから始まり、共通の Tailspin Toys シナリオを使用します。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan モードと Autopilot モード、命令、スキル、カスタム エージェント、Playwright Model Context Protocol (MCP)、Agent Merge、実用的なスラッシュ コマンドを体験します。

### [GitHub Copilot app][app]

デスクトップ アプリで並列エージェント セッションを実行し、セッション モードを切り替え、Canvas で共同作業し、GitHub Issue とプルリクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub Issue を非同期エージェントに割り当て、作業をガイドし、進行状況を監視して、作成されたプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに Copilot Chat のエージェント モード、Model Context Protocol (MCP) サーバー、カスタム エージェントを利用します。
